# AI-Powered Multi-Layer Phishing Website and Scam Email Detection

An AI/ML-based cybersecurity project for detecting phishing websites
and scam/phishing emails using multiple signals, risk analysis and
explainable results.

## Project Goals

- Phishing website and URL detection
- Scam/phishing email detection
- Email-to-URL correlation
- Explainable risk analysis
- Machine learning model comparison
- Practical browser-based detection

## Project Modules

1. Website/URL Detection
2. Scam Email Detection
3. Email-to-URL Correlation
4. Risk Analysis and Explainability
5. Backend API
6. Browser Extension
